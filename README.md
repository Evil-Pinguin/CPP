# EvilPin

Интерактивный прототип обучающей платформы компании EvilPin по C++ для аудитории 14+. Курс рассчитан на абсолютных новичков: первые задания требуют изменить только одно число, а новые понятия добавляются постепенно. Конечная цель — подвести ученика к программированию в Unreal Engine.

## Что внутри

- восемнадцать полноценных уроков: от первой переменной до игровых событий Unreal;
- до Unreal изучаются bool, параметры функций, массивы, классы и объекты;
- блок Unreal включает Actor, BeginPlay, Tick, компоненты, столкновения и таймеры;
- сложность растёт постепенно: от замены числа до настоящих вызовов Unreal C++;
- каждый урок начинается с короткой теории, после которой сразу идёт вопрос;
- дополнительные задания на перенос и закрепление навыка;
- задания в духе Duolingo: выбор ответа и сборка кода из карточек;
- маршрут обучения, XP, серия дней и прогресс;
- объяснение механики «без воды»;
- C++-редактор, подсказка и симуляция проверки кода;
- мини-тест с наградой за прохождение;
- сохранение прогресса в `localStorage`;
- временный тестовый режим: все 18 уроков доступны из маршрута без предварительного прохождения;
- адаптивный интерфейс в стиле liquid glass.

## Запуск

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run lint
npm run build
```
